# Продолжение работы на другой машине

1. Установить Git и Node.js 24.
2. Клонировать публичный репозиторий `https://github.com/zhenchur/rost-motion-lab.git` без авторизации, выполнить `npm ci` в его папке.
3. Выполнить `npm test`, `npm run test:mp4`, `npm run build`.
4. Запустить `npm run dev`, открыть адрес из терминала. Проверить `rost-fold` и `rost-fan`, паузу, скорость, толщину, плотность 50–200% (по умолчанию 100%), инверсию, SVG и MP4.
5. Для добавления новых паттернов открыть папку проекта в Codex и подключить Figma. Правила и проектный навык уже находятся в репозитории.
6. Открыть новый чат в `rost-motion-lab`. Для следующего паттерна передать скриншот со стрелками и отдельно чистый паттерн. Codex берёт точную ноду Figma из приложенных материалов или контекста и сам выполняет реализацию по [проектному навыку](../.agents/skills/rost-pattern-motion/SKILL.md), на который ссылается AGENTS.md. Уточнение ссылки нужно только если исходник неоднозначен.

В Git включены исходники реальных композиций, исходные SVG, lockfile, схема, тесты, самостоятельный HTML, проектный навык и инструкции. Пользователю не нужно готовить JSON, координаты или настраивать стрелки в приложении. Не включены `node_modules`, временные рендеры `.exports`, машинные настройки и токены. Файлы MP4 воспроизводятся командой экспорта.

Общий профиль `src/motion/pattern-profile.js` переносится вместе с проектом. Все следующие композиции наследуют оформление, толщину и последовательность интервалов первого РОСТ без растяжения под новый макет. Интервалы измеряются вдоль траекторий изломов; подробности и правило продолжения у камеры описаны в [MOTION-MODEL.md](MOTION-MODEL.md). Источники: `rost-fold` — Figma 2170:664, `rost-fan` — Figma 2179:1529.

Плотность меняет число линий на тех же траекториях без изменения исходных JSON, стиля и профиля интервалов. При её изменении сохраняются скорость движения, пауза, инверсия, толщина и фаза; при смене композиции — выбранные плотность, скорость и толщина. Проверьте, что статичный/анимированный SVG и MP4 учитывают эту настройку. Описание поведения и проектный навык переносятся вместе с исходниками.

## Проверки перед передачей

- Исходный РОСТ: 26 рядов × 36 точек, 4161 сэмпл движения и 11 440 сэмплов SVG; точная перестановка геометрии на стыке.
- Общая модель: реальный РОСТ и внутренние синтетические данные для контрактов движка; сравнение с исходной геометрией, прямые/обратные циклы, согласованность направлений и проверка некорректных данных. Демонстрационные композиции в приложение не включены.
- MP4: настоящее H.264/yuv420p, полное декодирование, кадровая длительность, faststart, прямой и обратный цикл. Локальный API проверен на создание, скачивание, отклонение чужого Origin и параллельного задания.
- Windows: Node.js 24.12.0. Шаблон проверок для Linux/Windows сохранён в `docs/ci/verify.yml`; GitHub Actions не активирован из-за отсутствия права `workflow` у текущей авторизации. Linux и macOS в этой сессии не запускались.
- Браузерный инструмент заблокировал просмотр localhost политикой доступа. Финальный визуальный осмотр нового интерфейса этим инструментом не подтверждён; геометрические и экспортные проверки выполнены отдельно.

После активации шаблона результат CI и commit можно проверить во вкладке Actions репозитория. Переданная модель не требует платных API и не отправляет композиции внешним сервисам: рендер MP4 выполняется локально.
