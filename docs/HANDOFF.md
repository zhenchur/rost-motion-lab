# Продолжение работы на другой машине

1. Установить Git и Node.js 24; войти в GitHub с доступом к приватным репозиториям.
2. Клонировать `zhenchur/rost-motion-lab`, выполнить `npm ci`.
3. Выполнить `npm test`, `npm run test:mp4`, `npm run build`.
4. Запустить `npm run dev`, открыть адрес из терминала. Проверить переключение композиций, стрелки, паузу, инверсию, SVG и MP4.
5. Для Codex отдельно клонировать `zhenchur/codex-frontend-kit`, прочитать README, проверить dry-run и применить установщик. Открыть новый чат в проекте, чтобы подхватились правила.

В Git включены исходники, JSON, исходные SVG, lockfile, схема, тесты, самостоятельный HTML и инструкции. Не включены `node_modules`, временные рендеры `.exports`, машинные настройки и токены. Файлы MP4 воспроизводятся командой экспорта.

## Проверки перед передачей

- Исходный РОСТ: 26 рядов × 36 точек, 4161 сэмпл движения и 11 440 сэмплов SVG; точная перестановка геометрии на стыке.
- Общая модель: 3 композиции, 6243 сэмпла геометрии, 2601 сравнение с исходным РОСТ, прямые/обратные циклы, согласованность стрелок и проверка некорректных данных.
- MP4: настоящее H.264/yuv420p, полное декодирование, кадровая длительность, faststart, прямой и обратный цикл. Локальный API проверен на создание, скачивание, отклонение чужого Origin и параллельного задания.
- Windows: Node.js 24.12.0. Шаблон проверок для Linux/Windows сохранён в `docs/ci/verify.yml`; GitHub Actions не активирован из-за отсутствия права `workflow` у текущей авторизации. Linux и macOS в этой сессии не запускались.
- Браузерный инструмент заблокировал просмотр localhost политикой доступа. Финальный визуальный осмотр нового интерфейса этим инструментом не подтверждён; геометрические и экспортные проверки выполнены отдельно.

После активации шаблона результат CI и commit можно проверить во вкладке Actions репозитория. Переданная модель не требует платных API и не отправляет композиции внешним сервисам: рендер MP4 выполняется локально.
