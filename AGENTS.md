# Р.О.С.Т. Motion Lab

Проект: Vite, vanilla JavaScript, GSAP, SVG. Не добавлять React, Tailwind или другой анимационный движок без задачи на миграцию.

- Общая геометрия и все экспорты используют `src/motion/model.js`. Новая композиция — JSON в `src/compositions/` и запись в `registry.js`. Модель описана в `docs/MOTION-MODEL.md`.
- Стрелки из референса сначала перевести в явные `from`, `to`, `vertex`. Не выдумывать автоматическое распознавание картинки. Проверить совпадение стрелок и реального движения в предпросмотре.
- Исходный `rost-fold` сохраняет точные осевые линии Figma 2170:664. Архивная геометрия в `scripts/fixtures` служит только регрессионным эталоном.
- Не менять геометрию, скорость, паузу, инверсию или вид сцены вне текущего запроса. Численные настройки должны совпадать в SVG, MP4 и плеере.
- Плеер изолирован; освобождать GSAP и обработчики в destroy. Учитывать reduced motion и скрытую вкладку.
- Проверки: `npm test`, `npm run build`; при изменении MP4 — `npm run test:mp4`. Для UI дополнительно открыть localhost, проверить нужный элемент и сохранить скриншот.
- Перед передачей проверять `npm ci`, тесты и сборку в чистой копии. Не включать node_modules, .exports, handoff, auth/config-токены и локальные логи в Git.
- MP4 API работает только на loopback dev/preview-сервере. Не открывать этот сервер наружу и не публиковать его как общедоступный сервис.
- Обновлять документацию и существенные проверки при изменении JSON-контракта или геометрии. Указывать фактически проверенные платформы.

Общие переносимые навыки и правила находятся в отдельном приватном репозитории `zhenchur/codex-frontend-kit`.
