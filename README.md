# Р.О.С.Т. Motion Lab

Самостоятельная модель анимации линейных паттернов на Vite, vanilla JavaScript, GSAP и SVG. Две реальные композиции — исходный `rost-fold` и новый `rost-fan`: SVG-обводки, плавный бесшовный поток, инверсия и экспорт SVG / MP4.

Новые композиции Codex собирает из чистого паттерна в Figma и скриншота со стрелками. Геометрия берётся из Figma, оформление линий — из существующей композиции, движение — из размеченного скриншота. В приложении нет редактора стрелок или готовых демонстрационных заготовок.

Общий профиль сохраняет цвет, толщину и перспективную последовательность интервалов первого РОСТ во всех композициях. Расстояния измеряются вдоль траекторий изломов; видимый зазор поперёк линии зависит от её наклона. Исходная композиция остаётся без изменений.

## На другой машине

Нужны Git и Node.js 24. Публичный репозиторий можно клонировать без авторизации в GitHub.

```sh
git clone https://github.com/zhenchur/rost-motion-lab.git
cd rost-motion-lab
npm ci
npm run dev
```

Откройте адрес из терминала, обычно http://127.0.0.1:5173. `npm ci` устанавливает также растеризатор SVG и FFmpeg для вашей ОС. Системная установка FFmpeg не нужна. Проверенная платформа — Windows с Node.js 24.12.0; Linux и macOS в этой сессии не запускались.

## Как дать Codex новый паттерн

Откройте репозиторий в Codex и передайте скриншот паттерна с нарисованными стрелками движения и отдельно чистый паттерн без разметки. Ноду Figma Codex берёт из приложенной ссылки или доступного контекста; уточняет её только если исходник нельзя однозначно найти.

Пример сообщения:

> Сделай анимацию этого паттерна. Чистый паттерн возьми из Figma, линии оформи как в существующем РОСТ. Направления движения показаны на скриншоте со стрелками. Сохрани бесшовный цикл, инверсию и выгрузку SVG/MP4.

Codex сам извлекает геометрию, переводит заполненные полосы в осевые SVG-обводки, сопоставляет стрелки с участками паттерна и меняет код. Рисовать траектории в приложении или вручную готовить координаты не требуется. Длина нарисованной стрелки сама по себе не задаёт скорость или конечную точку движения.

Процесс закреплён в [AGENTS.md](AGENTS.md) и проектном навыке [rost-pattern-motion](.agents/skills/rost-pattern-motion/SKILL.md). [Подробнее о подготовке новой композиции](docs/NEW-COMPOSITION.md).

## Предпросмотр и экспорт

- Пауза, скорость 0,25–2×, толщина обводки 0,25–24 и инверсия без сброса кадра.
- Общая плотность 50–200%, по умолчанию 100%: больше или меньше линий на тех же траекториях, с сохранением скорости движения. Исходные данные и профиль интервалов не меняются.
- Режим «Только паттерн».
- Текущий кадр SVG, анимированный SVG и MP4/H.264.
- Выбор между `rost-fold` и `rost-fan`; выбранные плотность, скорость и толщина сохраняются между композициями. Изменение плотности сохраняет также паузу, инверсию и текущую фазу цикла.

Статичный и анимированный SVG, а также MP4 учитывают выбранную плотность. Кнопка MP4 создаёт ролик 30 FPS, минимум 6 секунд с округлением до целого числа циклов. Учитываются текущая композиция, направление, скорость и толщина. Для РОСТ размер видео 1920 × 794: к исходным 793 строкам добавляется одна строка фона для совместимости H.264. Видео без звука.

```sh
npm run export:mp4 -- --composition rost-fold --output artifacts/rost-fold.mp4
npm run export:mp4 -- --composition rost-fold --inverted --seconds 2 --duration 8 --fps 60 --output artifacts/rost-reverse.mp4
```

[Параметры MP4](docs/MP4.md). Существующий файл заменяется только с `--overwrite`.

## Сборка и проверка

```sh
npm test
npm run test:mp4
npm run build
npm run preview
```

Сборка создаёт `dist/`, автономный `rost-preview.html` и SVG зарегистрированных композиций в `public/compositions/`. Прежние пути `public/rost-strokes.svg` и `public/rost-motion.svg` сохранены. В автономном HTML работают предпросмотр и SVG; для MP4 нужен локальный dev/preview-сервер или CLI.

`prefers-reduced-motion` останавливает плеер и показывает статичный кадр анимированного SVG. MP4 остаётся явно запрошенным анимированным экспортом.

Шаблон GitHub Actions для Windows/Linux: [docs/ci/verify.yml](docs/ci/verify.yml). Он не активирован: у использованной авторизации GitHub нет права `workflow`. Для включения перенесите файл в `.github/workflows/verify.yml` через авторизацию с нужным правом.

## Для разработки

| Путь | Назначение |
| --- | --- |
| .agents/skills/rost-pattern-motion | Процесс работы Codex с чистым паттерном и размеченным скриншотом |
| src/compositions | Данные реальных композиций, схема и реестр |
| src/motion/model.js | Общая геометрия, прозрачность и SVG-экспорт |
| src/motion/pattern-profile.js | Общие оформление, толщина и точные интервалы первого РОСТ |
| scripts/build-rost-fan.mjs | Подготовка второй композиции из Figma с общим профилем |
| src/player.js | GSAP-плеер, пауза, скорость и инверсия |
| scripts/render-mp4.mjs | Покадровый SVG → PNG → FFmpeg/H.264 |
| assets | Сохранённые векторные исходники Figma |

[Внутренний контракт модели](docs/MOTION-MODEL.md) предназначен для Codex и разработчика. Общий движок позволяет добавлять реальные паттерны без копирования плеера.

Исходные макеты: [rost-fold — Figma 2170:664](https://www.figma.com/design/RnBHxdFLuCb2eIb6NTBCap/?node-id=2170-664), [rost-fan — Figma 2179:1529](https://www.figma.com/design/RnBHxdFLuCb2eIb6NTBCap/?node-id=2179-1529). Для запуска сохранённых композиций доступ к Figma не нужен: рабочие ассеты находятся в репозитории.

Правила работы и проектный навык находятся в этом репозитории и переносятся вместе с ним. Для добавления новых паттернов через Codex подключите Figma и откройте папку проекта. [Проверка переноса](docs/HANDOFF.md).
