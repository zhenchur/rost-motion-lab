# Р.О.С.Т. Motion Lab

Расширяемая модель плавного движения SVG-линий по стрелкам. Три композиции, общий движок, бесшовный цикл, редактирование стрелок, инверсия и экспорт SVG / MP4.

## На другой машине

Нужны Git и Node.js 24. Проверено на Windows с Node.js 24.12.0. Linux и macOS используют тот же исходный код и npm-пакеты, но в этой сессии не запускались.

```sh
git clone https://github.com/zhenchur/rost-motion-lab.git
cd rost-motion-lab
npm ci
npm run dev
```

Откройте адрес из терминала, обычно http://127.0.0.1:5173. Репозиторий приватный — для клонирования нужна авторизация в GitHub под аккаунтом с доступом.

`npm ci` также устанавливает растеризатор SVG и FFmpeg для вашей ОС. Системная установка FFmpeg не нужна. Поддерживаемые архитектуры и ограничения описаны в [MP4.md](docs/MP4.md).

## Что можно сделать

- Выбрать «РОСТ», «Коридор» или «Шеврон».
- Показать стрелки. В «Коридоре» и «Шевроне» перетащить белые конечные точки или изменить их клавишами стрелок после фокусировки. Движение пересчитается после отпускания указателя. У исходного РОСТ стрелки задают направление для точной геометрии макета.
- Сохранить композицию в JSON и загрузить её на другом компьютере. Сохранённый JSON содержит модель и стрелки; временные настройки скорости, инверсии и толщины плеера отдельно учитываются экспортом SVG/MP4.
- Изменить скорость 0,25–2×, stroke 0,25–24, поставить на паузу или включить инверсию без сброса кадра.
- Скачать текущий кадр SVG, анимированный SVG или настоящий MP4/H.264. Стрелки интерфейса в экспорт не попадают.

Кнопка MP4 создаёт ролик 30 FPS, минимум 6 секунд с округлением до целого числа циклов. Экспорт учитывает текущую композицию, направление, скорость и толщину. Для РОСТ размер видео 1920 × 794: к исходным 793 строкам добавляется одна строка фона для совместимости H.264. Видео без звука.

## Новая композиция

[Пошаговая инструкция](docs/NEW-COMPOSITION.md) · [Контракт модели](docs/MOTION-MODEL.md) · [Шаблон JSON](docs/templates/composition.json)

1. Передайте Codex макет или изображение с геометрией и стрелками направления. Укажите размер композиции, желаемые скорость и толщину.
2. Codex переводит стрелки в координаты `from → to`, связывает их с вершинами и создаёт JSON. Автоматического распознавания нарисованных стрелок в приложении нет.
3. Загрузите JSON через «Загрузить композицию» и проверьте результат. Для постоянного включения добавьте файл в `src/compositions/` и импорт в `registry.js`.

Вариант `sampled-rows` сохраняет точные исходные ряды. Вариант `arrow-field` строит траекторию каждой вершины по стрелке. Модель проверяет формат, направление и условия цикла; это не универсальный движок для любых 3D-сцен, частиц или деформируемых кривых. Для таких задач добавляется новый версионированный тип модели.

## Экспорт из терминала

```sh
npm run export:mp4 -- --composition rost-fold --output artifacts/rost-fold.mp4
npm run export:mp4 -- --composition chevron --inverted --seconds 2 --duration 8 --fps 60 --output artifacts/chevron.mp4
npm run export:mp4 -- --composition ./my-composition.json --output artifacts/custom.mp4
```

[Параметры и формат видео](docs/MP4.md). Существующий MP4 заменяется только с `--overwrite`.

## Сборка и проверка

```sh
npm test
npm run test:mp4
npm run build
npm run preview
```

Шаблон GitHub Actions для Windows/Linux: [docs/ci/verify.yml](docs/ci/verify.yml). Он пока не активирован: у использованной авторизации GitHub нет права `workflow`. Чтобы включить CI, перенесите файл в `.github/workflows/verify.yml` через авторизацию с нужным правом. Локальные команды проверки работают независимо от CI.

Сборка создаёт:

- `dist/` — клиентское приложение. Через `npm run preview` доступен и локальный MP4 API. При размещении только статических файлов на хостинге MP4 API отсутствует.
- `rost-preview.html` — автономный HTML без внешних ассетов: композиции, редактирование стрелок, JSON и SVG работают без сервера. Для MP4 запустите dev/preview либо CLI.
- `public/compositions/` — самостоятельные SVG всех композиций. `public/rost-strokes.svg` и `public/rost-motion.svg` сохраняют прежние пути.

`prefers-reduced-motion` останавливает плеер и показывает статичный кадр анимированного SVG. MP4 — явно запрошенный экспорт видео и остаётся анимированным.

## Структура

| Путь | Назначение |
| --- | --- |
| src/compositions | Версионированные данные, JSON Schema и реестр |
| src/motion/model.js | Валидация, геометрия, прозрачность, SVG-экспорт |
| src/player.js | Изолированный GSAP-плеер, пауза, скорость и направление |
| src/main.js | Интерфейс, импорт, стрелки, выгрузка |
| scripts/render-mp4.mjs | Покадровый SVG → PNG → FFmpeg/H.264 |
| scripts/mp4-server.mjs | Локальная очередь экспорта для dev/preview |
| scripts/fixtures | Эталон исходной геометрии для регрессионной проверки |
| assets | Сохранённые векторные исходники Figma |

Исходный макет: [Figma 2170:664](https://www.figma.com/design/RnBHxdFLuCb2eIb6NTBCap/?node-id=2170-664). Все рабочие ассеты находятся в репозитории; доступ к Figma для запуска не нужен.
